The method

From dependency map to decision, in four moves.

01

Map

List business processes and the systems each one depends on.

02

Target

Set a recovery time (RTO), a data-loss limit (RPO) and an hourly cost for each process.

03

Break

Trigger a scenario and watch failures cascade through the dependency graph.

04

Treat

Compare mitigate, transfer, avoid and accept, then re-run to see the gap close.

Cascade engine

One failure never stays one failure.

A database outage takes the API down, and the API takes payments and orders with it. ResilienceLab follows every dependency so you see the full blast radius, not just the first system that broke.
